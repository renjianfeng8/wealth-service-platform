# 404 页面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建 404 页面组件并更新路由，替代当前静默重定向到 /home 的行为

**Architecture:** 独立页面（不嵌套布局），全屏居中显示，纯 CSS 实现渐变文字和装饰 SVG

**Tech Stack:** Vue 3 + Element Plus + TypeScript + Vue Router

### Task 2: 修改路由配置

**Files:**
- Modify: `front/src/router/index.ts:70-71`

- [ ] **Step 1: 替换 404 路由指向**

将：
```typescript
{ path: '/:pathMatch(.*)*', redirect: '/home' },
```

改为：
```typescript
{ path: '/:pathMatch(.*)*', name: 'NotFound', component: () => import('@/views/error/NotFound.vue') },
```

- [ ] **Step 2: 验证路由**

确认修改后：
- 访问 `/nonexistent` 显示 404 页面而非跳转首页
- 访问 `/home`、`/products` 等正常路由不受影响
- 404 页面独立显示（无 UserLayout/AdminLayout 嵌套）
- "返回首页" 按钮正确跳转 `/home`
- "返回上一页" 按钮正常工作
