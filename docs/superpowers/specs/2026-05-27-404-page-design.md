# 404 页面设计

## 概述

为前端补充 404 页面，替代当前将未知路由静默重定向到 `/home` 的行为。

## 页面布局

独立页面（不嵌套 UserLayout / AdminLayout），全屏居中布局，flex 垂直居中。

## 视觉构成

| 元素 | 样式 |
|------|------|
| "404" 文字 | 120px（桌面）/ 72px（移动端），字重 800，渐变 `linear-gradient(135deg, #1a6dff, #0a4dcc)`，`background-clip: text` |
| 装饰 SVG | 纯 CSS 断环 SVG（空心圆环带缺口），宽高 120px，描边色 `#e5e5ea` |
| 标题 | "页面未找到"，24px，字重 600，色 `var(--text-primary)` |
| 描述 | "抱歉，您访问的页面不存在或已被移除"，14px，色 `var(--text-secondary)` |
| 返回首页按钮 | `el-button` 主色渐变风格，点击跳转 `/home` |
| 返回上一页 | `el-button text` 风格，点击 `router.back()` |

## 文件位置

- 组件：`front/src/views/error/NotFound.vue`
- 样式：scoped style 内联于组件

## 路由变更

```diff
- { path: '/:pathMatch(.*)*', redirect: '/home' },
+ { path: '/:pathMatch(.*)*', name: 'NotFound', component: () => import('@/views/error/NotFound.vue') },
```

## 状态覆盖

- 正常访问 404：显示完整页面，含返回首页/返回上一页
- 通过 router.push 等编程导航到不存在的路由：同上
- 无需加载态、空态、错误态（页面本身就是错误态展示）
